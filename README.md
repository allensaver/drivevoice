# DriveVoice

车载全双工 Voice AI 产品项目（个人产品项目，非任职经历）。

独立完成的一段完整产品项目：从竞品分析、用户画像、技术调研，到评测体系与 bad case 归因、三大核心功能设计，并为其中的「打断（barge-in）功能」写了完整 PRD 与迭代路线图。

## 内容

- `drivevoice-project.pdf` — 项目总文档（展示版）：项目概述、竞品分析、用户画像、技术调研、评测与 bad case 五层归因、三大核心功能、打断功能完整 PRD、路线图与项目复盘。
- `DriveVoice-120-test-cases.xlsx` — 120 条车载语音评测用例：A 基础车控 25 / B 导航 25 / C 多意图 20 / D 打断纠错 20 / E 噪声与复杂环境 15 / F 模糊表达与闲聊 15，含评分口径与自动汇总（实测结果列留空，供本人实测填写）。

## 核心方法

- 评测先行：先建用例集与统一口径，再谈功能效果。
- Bad case 五层归因：感知 / 理解 / 规划 / 执行 / 生成安全，先归因再改方案。
- 安全优先：高风险动作先确认再执行，确认只对同一动作与对象有效。
